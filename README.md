# Banking Transactions Analysis

## About the Project

I created this project to analyse banking transaction data and understand transaction activity, customer behaviour and transaction performance.

The project focuses on questions that could be useful for a bank, such as which transaction types and channels are most commonly used, where failed transactions occur, and which areas generate the highest transaction value.

## Tools Used

- Excel
- PostgreSQL / SQL
- Power BI

## What I Did

- Cleaned the transaction dataset in Excel.
- Selected the relevant columns for the analysis.
- Prepared the data for SQL analysis.
- Loaded the data into PostgreSQL.
- Used SQL to analyse transaction patterns and performance.
- Created a interactive Power BI dashboard to present the results.

## SQL Analysis

I used SQL to answer questions such as:

- How many transactions were successful or failed?
- Which transaction type has the highest activity?
- Which transaction channel is used most often?
- What is the average transaction amount by transaction type?
- Which transaction type has the most failed transactions?
- Which account type has the most transactions?
- Which merchant categories have the highest transaction activity?
- Which transaction types have the highest total transaction value?
- At what times of the day are transactions most common?

## Power BI Dashboard

I created an interactive Power BI dashboard to give a quick overview of banking transaction activity.

The dashboard includes key figures and visualisations covering transaction status, transaction types, transaction channels, account types and transaction values.

## Project Files
